# Projeto Agrinho 2026 - Davi 1B

Site educativo desenvolvido para o Projeto Agrinho, com foco no uso de drones agrícolas no Brasil.

## Objetivo

Apresentar, de forma visual e interativa, como drones ajudam no campo com monitoramento, mapeamento, pulverização de precisão e melhoria da produtividade.

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript (vanilla)
- Google Fonts (`Poppins`)

## Estrutura do projeto

- `index.html`: página principal com conteúdo sobre drones no agro.
- `agrinho.html`: página do projeto Agrinho e apresentação do aluno.
- `styles.css`: estilos visuais, layout responsivo, animações e componentes.
- `script.js`: interações da interface (menu mobile, galeria paginada, contadores, animações de entrada e botão voltar ao topo).
- `img/`: imagens locais usadas no site (galeria e perfil do aluno).

## Funcionalidades

- Menu responsivo para dispositivos móveis.
- Seções com animação de revelação ao rolar a página.
- Galeria com paginação (`Anterior`, `Próxima` e seleção por número).
- Fallback automático de imagens da galeria para URLs externas em caso de erro.
- Contadores animados na seção de destaque.
- Botão flutuante para voltar ao topo com rolagem suave.

## Como executar

1. Abra a pasta do projeto.
2. Execute o arquivo `index.html` no navegador.
3. Para uma navegação completa, acesse também `agrinho.html`.

Opcional com servidor local:

- No VS Code, use a extensão Live Server.
- Ou rode um servidor estático local de sua preferência.
